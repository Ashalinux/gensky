## Join the server

1. Start **Minecraft Java Edition**
2. Open **Multiplayer → Add Server**
3. Enter **`gensky.online`** and join

<br />

## What is Gensky?

Gensky is a **Skyblock server built around generators**. You start on your own island in the sky, place generators that produce resources, sell what you farm and slowly grow from a few blocks into a huge, automated base.

Unlike most servers, Gensky doesn't run on Paper or Spigot. It runs on a **custom server written from scratch** on top of [Minestom](https://minestom.net/) – every mechanic was built by hand for a fast, lag-free Skyblock experience.

<br />

## Features

**Your island**
- Private island with coop members, island settings and protection
- Expand your island and climb the island-size leaderboard

**Generators & automation**
- Placeable, upgradeable **block generators**
- **Mining dwarfs** – companions that mine your generators for you
- **Range hoppers**, sell sticks, sort sticks and upgradeable **mob spawners**
- A **recycler** that turns crafted items back into their ingredients

**Economy & progression**
- Player economy with sell stations and a shop
- Daily rewards, crates, progression and ranks
- **Top 10 leaderboards** for balance, playtime, reputation and island size

**Community**
- Clans, trading, private messages and team chat
- Jetpacks, pets, double jump, jump pads and much more
- Regular **events** – like the Halloween event on 23.10.2026
- **Daily discount code** for the shop, the same for every visitor
